Capacitacion sobre MCP utilizando fast mcp

# Requerimientos Funcionales

## El sistema debe permitir:
- Crear usuarios.
- Autenticar usuarios mediante credenciales.
- Generar Access Tokens JWT.
- Validar tokens JWT.
- Refrescar tokens expirados o próximos a expirar.
- Almacenar usuarios y tokens en SQLite.
- Configurar expiración de tokens a 1 hora.
- Exponer funcionalidades mediante endpoints HTTP REST.
- Realizar cambio de divisas de una moneda a otra
